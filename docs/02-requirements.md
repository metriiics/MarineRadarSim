# 02. Требования

Приоритеты: **M** — Must (MVP), **S** — Should (этап 2), **C** — Could (этап 3+).
Ориентир по функциям РЛС/САРП — эксплуатационные требования IMO MSC.192(79) и стандарт IEC 62388.
Тренажёр **не сертифицируется** на соответствие им, стандарты используются как источник правильного
поведения и допусков.

## 2.1. Функциональные требования

### Жизненный цикл РЛС (SYS)

| ID | Требование | Пр. |
|----|------------|-----|
| FR-SYS-001 | Состояния РЛС: ВЫКЛ → ПРОГРЕВ → ГОТОВ (STANDBY) → ИЗЛУЧЕНИЕ (TX). Переходы только допустимые | M |
| FR-SYS-002 | Время прогрева настраивается в конфигурации (по умолчанию 90 с, в учебных целях можно сократить) | M |
| FR-SYS-003 | В STANDBY изображения нет, органы индикации активны; в TX — вращение антенны и эхо | M |
| FR-SYS-004 | Система генерирует события и тревоги (журнал + индикация), тревоги квитируются оператором | M |
| FR-SYS-005 | Имитация неисправностей (нет данных гирокомпаса/лага/ГНСС, отказ магнетрона) по сценарию | S |

| ID | Требование | Пр. |
|----|------------|-----|
| FR-RAD-001 | Вращение антенны с заданной скоростью (по умолчанию 24 об/мин), развёртка ИКО синхронна антенне | M |
| FR-RAD-002 | Шкалы дальности: 0.25, 0.5, 0.75, 1.5, 3, 6, 12, 24, 48, 96 мили; кольца дальности по шкале | M |
| FR-RAD-003 | Длительность импульса (КИ/СИ/ДИ) выбирается автоматически по шкале или вручную; влияет на разрешение и дальность обнаружения | M |
| FR-RAD-004 | Эхо от целей с учётом ЭПР, дальности, радиогоризонта, ширины ДН антенны, длительности импульса | M |
| FR-RAD-005 | Эхо от берега (полигоны береговой линии с высотой) и радиолокационные тени | M |
| FR-RAD-006 | Собственные шумы приёмника | M |
| FR-RAD-007 | Помехи от моря, зависящие от балльности и направления ветра; регулировка ВОД (STC) | M |
| FR-RAD-008 | Помехи от осадков (зоны дождя); регулировка ДОЖДЬ (FTC) | M |

| FR-RAD-010 | АПЧ: ручная/автоматическая подстройка, расстройка снижает чувствительность | S |
| FR-RAD-011 | Подавление несинхронных помех (ПНП/IR) от «чужих РЛС» | S |
| FR-RAD-012 | Ложные эхо: боковые лепестки, многократные отражения, теневые сектора от надстроек | C |
| FR-RAD-013 | Послесвечение (след на экране) настраиваемой длительности | M |

### Индикация и режимы (DSP)

| ID | Требование | Пр. |
|----|------------|-----|
| FR-DSP-001 | Ориентация: Север (N-Up), Курс (C-Up), Нос (H-Up, «ВН») | M |
| FR-DSP-002 | Движение: относительное (ОД/RM) и истинное (ИД/TM) с автосбросом центра | M |
| FR-DSP-003 | Смещение центра (off-centre) до 66 % радиуса | S |
| FR-DSP-004 | Отметка курса (линия курса), её временное скрытие | M |
| FR-DSP-005 | ЭВН (EBL) ×2 и ПКД/ВД (VRM) ×2 с цифровыми значениями | M |
| FR-DSP-006 | Курсор: пеленг/КУ, дальность, широта/долгота точки | M |
| FR-DSP-007 | Параллельные индексные линии (PI) | S |
| FR-DSP-008 | Часы (время сценария с часовым поясом), данные собственного судна (курс, скорость, координаты) | M |
| FR-DSP-009 | Ночной/дневной режимы яркости | S |

### САРП / сопровождение целей (TT)

| ID | Требование | Пр. |
|----|------------|-----|
| FR-TT-001 | Ручной захват цели курсором, сброс цели, сброс всех | M |
| FR-TT-002 | Автозахват в зонах охраны (до 2 зон), тревога входа в зону | S |
| FR-TT-003 | Сопровождение ≥ 40 целей (IEC 62388 категория для судов ≥ 10 000 GT; минимум для MVP — 20) | M |
| FR-TT-004 | Тренд движения в течение 1 мин, устойчивые векторы в пределах 3 мин после захвата | M |
| FR-TT-005 | Векторы: относительные / истинные, время вектора 1–60 мин | M |
| FR-TT-006 | Прошлые позиции (следы / точки отклонений) — ≥ 4 отметки с выбираемым интервалом | M |
| FR-TT-007 | Данные выбранной цели: пеленг, дальность, курс(И), скорость(И), ДКС, ВКС, ДПК, ВПК, широта, долгота | M |
| FR-TT-008 | Тревога «Опасная цель» при ДКС < пред. ДКС и 0 < ВКС < пред. ВКС | M |
| FR-TT-009 | Тревога «Цель потеряна» при отсутствии отметок N обзоров подряд | M |
| FR-TT-010 | Проигрывание манёвра (trial manoeuvre) с задержкой выполнения | S |
| FR-TT-011 | Стабилизация по воде / по грунту (ввод скорости лага / ГНСС, опорная цель) | S |
| FR-TT-012 | Обмен целей (swap) при близком прохождении — воспроизводится как реальный эффект сопровождения | C |

## 2.2. Нефункциональные требования

| ID | Требование | Значение |
|----|------------|----------|
| NFR-PERF-001 | Частота кадров ИКО | ≥ 30 FPS на шкале 12 миль при 40 целях, офисный ПК (4 ядра, встроенная графика) |
| NFR-PERF-002 | Шаг симуляции | Фиксированный, по умолчанию 20 мс (50 Гц); видео генерируется по фактическому углу антенны |
| NFR-PERF-003 | Задержка реакции на органы управления | ≤ 100 мс от действия до изменения индикации |
| NFR-PERF-004 | Ускорение времени ×8 без пропуска логики (видео может прореживаться) | — |
| NFR-DET-001 | Детерминизм ядра | Один сценарий + seed + журнал команд → побитно одинаковое состояние на каждом такте (одна сборка/платформа) |
| NFR-REL-001 | Отказоустойчивость | Ошибка в файле сценария не роняет приложение, а выводит сообщение |
| NFR-REL-002 | Сеанс 4 ч без деградации | Нет роста памяти > 50 МБ, нет снижения FPS |
| NFR-MNT-001 | Слой domain не зависит от Qt | Проверяется сборкой (отдельная CMake-цель без Qt) |
| NFR-MNT-002 | Покрытие тестами domain/training | ≥ 70 % строк, математика САРП — 100 % ветвлений |
| NFR-MNT-003 | Стиль | clang-format + clang-tidy без предупреждений в CI |
| NFR-PRT-001 | Платформы | Linux (GCC ≥ 12, Debian 12), Windows (MSVC 2022) |
| NFR-USE-001 | Язык интерфейса | Русский; строки через Qt tr() для возможной локализации |
| NFR-USE-002 | Экран | Целевой — 1280×1024 (5:4, SXGA); на других экранах композиция центрируется, ИКО масштабируется |
| NFR-INS-001 | Установка | Без прав администратора, без сети; один каталог / один установщик |
