# 03. Предметная модель РЛС

Документ описывает **что и как моделируется** — физику и математику, которую реализует Simulation Core.
Цель модели — не точный электродинамический расчёт, а **правдоподобное поведение**, при котором верны
причинно-следственные связи, которым учат оператора (чем больше ВОД — тем меньше помех у центра и
тем легче потерять близкую малую цель, и т. п.).

## 3.1. Единицы и системы координат

### Единицы

Внутри ядра — только СИ: метры, секунды, радианы, м/с. Морские единицы — только на границе (UI, файлы).

| Величина | Внутри | Снаружи | Перевод |
|----------|--------|---------|---------|
| Расстояние | м | морская миля (NM), кабельтов | 1 NM = 1852 м, 1 кбт = 185.2 м |
| Скорость | м/с | узел (kn) | 1 kn = 1852/3600 м/с |
| Угол | рад | градусы | — |
| Время | с (double, время сценария) | ЧЧ:ММ:СС | — |

В коде — строгие типы (`Meters`, `MetersPerSecond`, `Radians`, `Bearing`), чтобы нельзя было сложить
мили с метрами (см. [04-architecture.md](04-architecture.md), модуль `core`).

### Системы координат

| Система | Описание | Где используется |
|---------|----------|------------------|
| **Геодезическая** (WGS-84, φ, λ) | Широта/долгота | Файлы сценариев, индикация курсора и целей |
| **Локальная мировая** (ENU, x — восток, y — север, м) | Плоская касательная проекция от точки начала сценария | Вся физика и движение |
| **Полярная от антенны** (D, П) | Дальность, истинный пеленг | Генерация видео, САРП |
| **Относительная** (D, КУ) | Курсовой угол от диаметральной плоскости | Отображение в режиме «Нос», ЭВН |
| **Экранная** (px) | Пиксели виджета ИКО | Только UI |

Проекция: равнопромежуточная от начала координат (`x = R·Δλ·cos φ0`, `y = R·Δφ`), R = 6 371 000 м.
Для района сценария радиусом ≤ 100 миль ошибка пренебрежимо мала для учебных целей.
Пеленг отсчитывается от севера по часовой стрелке: `П = atan2(x, y)` (именно `(x, y)`, не `(y, x)`).

## 3.2. Время и такт симуляции

* Фиксированный шаг `dt` (по умолчанию 20 мс). Время сценария `t = tick · dt` — целое число тактов, чтобы
  исключить накопление ошибки.
* Порядок обработки такта строго фиксирован (детерминизм):
  1. применить команды оператора, поступившие к этому такту;
  2. события сценария (манёвры, появление целей, отказы);
  3. движение собственного судна и целей;
  4. окружающая среда (дрейф зон дождя);
  5. поворот антенны → генерация новых спиц (spokes) видео за сектор `[θ(t−dt), θ(t))`;
  6. обработка видео: выделение отметок (plot extraction) — по мере завершения обзора секторов;
  7. сопровождение САРП, расчёт ДКС/ВКС, тревоги;
  8. оценивание (training) — читает состояние, ничего не меняет;
  9. публикация снимка состояния (snapshot) для UI.
* Все случайные величины — из `Rng`, инициализированного seed сценария; у каждой подсистемы свой поток
  (`seed ⊕ hash("sea_clutter")` и т. д.), чтобы добавление новой подсистемы не меняло случайность остальных.

## 3.3. Параметры РЛС (типовые для X-диапазона)

| Параметр | Обозначение | Типовое значение |
|----------|-------------|------------------|
| Частота / длина волны | f / λ | 9410 МГц / 3.2 см |
| Импульсная мощность | Pt | 12–25 кВт |
| Длительность импульса | τ | КИ 0.07 мкс, СИ 0.3 мкс, ДИ 0.8 мкс |
| ЧПИ (частота повторения) | PRF | 3000 / 1500 / 750 Гц (по τ) |
| Ширина ДН в горизонт. плоскости | θ_az | 1.0–1.9° (по длине антенны) |
| Ширина ДН в верт. плоскости | θ_el | 20–25° |
| Скорость вращения | Ω | 24 об/мин (обзор 2.5 с) |
| Высота антенны | h_a | 15–30 м |
| Коэффициент шума приёмника | NF | 5–7 дБ |

Значения задаются файлом `config/radars/<model>.yaml` (см. [06-scenarios-and-config.md](06-scenarios-and-config.md)).

## 3.4. Дискретизация видео

Видео моделируется как **полярный растр**: спица (spoke) = одно азимутальное направление, разбитое на
ячейки дальности (range bins).

* Азимутальных спиц на оборот: `N_az = 2048` (шаг 0.176°, мельче ширины луча).
* Ячеек дальности: `N_r = 1024` на текущую шкалу (шаг = шкала / 1024; на 12 милях ≈ 21.7 м).
  При смене шкалы растр пересчитывается со следующего оборота (как у реальной РЛС).
* Значение ячейки — амплитуда видеосигнала `uint8` (0…255) после всей обработки приёмника.
* Объём: 2048 × 1024 = 2 МБ на оборот; генерация ≈ 820 спиц/с — ~0.8 млн ячеек/с, с запасом
  укладывается в один поток.

## 3.5. Цепочка формирования сигнала

```text
Мир (цели, берег, море, дождь)
   │  для каждой спицы θ и ячейки r
   ▼
Мощность эхо целей + берега   P_t(r, θ)  ← уравнение РЛС, ДН антенны, горизонт, тени
Мощность помех моря           P_s(r, θ)  ← балльность, ветер, флуктуации
Мощность помех дождя          P_p(r, θ)  ← зоны осадков, ослабление
Шум приёмника                 P_n        ← NF, полоса
   ▼
Сумма → логарифмический приёмник → ВОД (STC) → ДОЖДЬ (FTC) → УСИЛЕНИЕ → квантование 8 бит
   ▼
Спица видео (uint8[N_r]) → ИКО (UI) и экстрактор отметок (САРП)
```

### 3.5.1. Уравнение РЛС (в относительной форме)

Абсолютная калибровка не нужна; используется отношение сигнал/шум (ОСШ) относительно опорной точки:

```
SNR(R) = SNR_ref · (σ / σ_ref) · (R_ref / R)^4 · F^4(R) · G²(Δθ) · L_rain(R) · K_τ
```

* `SNR_ref` — ОСШ эталонной цели `σ_ref = 10 м²` на `R_ref = 10 NM` при ДИ (параметр модели РЛС; подбирается
  так, чтобы дальность обнаружения соответствовала паспорту оригинала);
* `σ` — ЭПР цели (м²), с флуктуациями (см. 3.5.3);
* `F(R)` — множитель распространения: ≈1 до радиогоризонта, далее резкий спад (интерференционная модель
  над морем — этап 2);
* `G(Δθ)` — односторонняя ДН антенны по мощности, `Δθ` — отклонение направления на цель от оси луча
  (в формуле `G²` — путь туда и обратно). Модель главного лепестка: `G = (sin u / u)²`, `u = 2.78·Δθ/θ_az`
  (половинная мощность при `Δθ = θ_az/2`); боковые лепестки — константа −25…−30 дБ;
* `L_rain` — двустороннее ослабление в осадках (дБ/км × путь в зоне дождя × 2);
* `K_τ` — выигрыш от длительности импульса (энергия ∝ τ): `K_τ = τ / τ_ДИ`.

### 3.5.2. Радиогоризонт

С учётом рефракции (k = 4/3):

```
D_гор [NM] ≈ 2.23 · (√h_a + √h_t),   h — в метрах
```

Пример: h_a = 20 м, h_t = 10 м → D ≈ 2.23 · (4.47 + 3.16) ≈ 17 миль. Цель за горизонтом не даёт эхо
(или даёт только надстройкой, если задана высота мачты).

### 3.5.3. Модель цели

* Цель — протяжённый объект: длина `L`, ширина `B`, ЭПР `σ`, высота `h`.
  Протяжённость по дальности и азимуту даёт отметку, размер которой зависит от ракурса и длины импульса.
* Упрощённая эмпирика ЭПР судна (X-диапазон): `σ ≈ 52 · f[МГц]^0.5 · D[кт]^1.5` (Скольник), где D —
  водоизмещение в тысячах тонн. Для маленьких целей (буй, яхта) — явное значение в сценарии.
* Флуктуации ЭПР от обзора к обзору — модели Сверлинга (Swerling I для судов, Swerling 0 для уголковых
  отражателей). Это даёт «мерцание» и пропуски слабых целей — важно для обучения.

### 3.5.4. Разрешающая способность и размер отметки

* По дальности: `ΔR = c·τ / 2` (СИ 0.3 мкс → 45 м). Эхо растягивается на `ΔR` от передней кромки.
* По азимуту: отметка «размазывается» на ширину луча `θ_az` → точечная цель на 10 милях имеет
  угловой размер ≈ 0.3 мили. Две цели ближе `θ_az·R` сливаются.

### 3.5.5. Берег и тени

* Береговая линия — полигоны с высотой рельефа (одна высота на полигон в MVP, растр высот — этап 3).
* Для каждой спицы: пересечение луча с полигонами → отрезки дальности суши; эхо суши в этих ячейках
  с текстурным шумом; за первым сильным препятствием — тень (эхо ослабляется / отсутствует),
  кроме участков, чья высота выше линии визирования.
* Для производительности пересечения кэшируются по спицам для текущей позиции судна и
  пересчитываются при смещении > 0.5 ячейки дальности.

### 3.5.6. Помехи от моря

```
P_s(r, θ) = A(SS) · (r_0 / r)^3 · W(θ − θ_wind) · ξ        (r ≤ r_crit)
            ... · (r_crit / r)^4 дополнительно за r_crit
```

* `A(SS)` — интенсивность от балльности моря (0–6), таблица в конфиге;
* `W` — анизотропия: с наветренной стороны сильнее (до +6 дБ), с подветренной слабее;
* `r_crit` — критическая дальность (≈ 3–6 миль для X-диапазона), за ней помехи быстро исчезают;
* `ξ` — флуктуации: распределение Вейбулла / K (пиковость, «острые» выбросы), корреляция от обзора к
  обзору низкая.

### 3.5.7. Помехи от осадков

* Зоны дождя — эллипсы/полигоны с интенсивностью мм/ч, дрейфуют с ветром.
* Отражение объёмное: `P_p ∝ Z · V_cell / r²`, где `Z` — отражаемость от интенсивности, `V_cell` —
  объём импульсного объёма (растёт с `r` и `τ`). Отсюда характерная «вата» с размытыми краями.
* Ослабление за зоной дождя (см. `L_rain`) — цели за дождём ослабевают.

### 3.5.8. Приёмник и регулировки оператора

| Регулировка | Модель | Эффект для оператора |
|-------------|--------|----------------------|
| **УСИЛЕНИЕ** | Смещение порога логарифмического видео: `v = clamp(k_g · (log P − T_0), 0, 255)` | Мало — теряются слабые цели; много — экран засыпан шумом |
| **ВОД** (МВ, STC, anti-clutter sea) | Вычитание кривой `STC(r) = S · (r_0/r)^n` до `r_stc`, n≈3…4 | Подавляет помехи моря у центра, но и слабые близкие цели |
| **ДОЖДЬ** (FTC, anti-clutter rain) | Дифференцирование видео по дальности (ВЧ-фильтр, постоянная времени ∝ значению регулятора) | Остаются передние фронты отметок; «вата» дождя разрежается |
| **АПЧ** | Расстройка Δf → коэффициент потерь `L_afc = 1/(1+(Δf/B)²)` | В ручном режиме неправильная подстройка ослабляет все эхо |
| **ПНП** (IR) | Корреляция соседних спиц: подавление ячеек, не подтверждённых на соседних азимутах | Убирает «спирали» от чужих РЛС |

Шум приёмника: комплексный гауссов → релеевская амплитуда; в лог-шкале — стабильный «шумовой фон».

### 3.5.9. Пропорции и калибровка

Все коэффициенты (`SNR_ref`, `A(SS)`, `k_g`, `T_0`…) — в конфигурации модели РЛС. Калибровка выполняется
по эталонным ситуациям: «буй σ=1 м² обнаруживается на ≥ N милях при спокойном море», «судно 5000 т — на
≥ M милях», «при волнении 4 балла помехи до ~3 миль» — значения из руководства оригинала (Q-002).

## 3.6. САРП: от видео к сопровождаемым целям

### 3.6.1. Выделение отметок (plot extraction)

1. Порог по видео (адаптивный, CA-CFAR по скользящему окну дальности — MVP: фиксированный порог +
   локальное среднее).
2. Связные области ячеек выше порога в полярном растре → кластер.
3. Отметка (plot): центр масс по амплитуде (дальность, пеленг), протяжённость, амплитуда, время
   середины облучения.
4. Отметка формируется, когда антенна прошла кластер целиком (+ ширина луча).

Выделение работает **по тому же видео**, которое видит оператор (с его регулировками). Поэтому плохая
настройка УСИЛЕНИЯ/ВОД ухудшает сопровождение — как в реальности. Это ключевой учебный эффект.

### 3.6.2. Сопровождение (tracking)

* Фильтр: Калмана с моделью «почти постоянная скорость» (CV), состояние `[x, y, vx, vy]` в мировой
  системе (стабилизация по грунту) или относительно воды (по лагу).
* Ворота стробирования: эллипс по ковариации инновации (χ², p = 0.99), минимальный размер — от точности
  измерений (по дальности ~ΔR, по пеленгу ~θ_az/4).
* Ассоциация: глобальный ближайший сосед (GNN, венгерский алгоритм или жадный по расстоянию для MVP).
* Состояния трека:

```text
 ЗАХВАТ ──(подтверждение M из N обзоров)──► СОПРОВОЖДЕНИЕ
    │                                          │   ▲
    │ нет отметок                    нет отметки│   │ отметка
    ▼                                          ▼   │
 СБРОС ◄──(K обзоров без отметки)──────── ЭКСТРАПОЛЯЦИЯ ──► ПОТЕРЯНА (тревога)
```

* Начальная фаза: ~1 мин — отображается тренд, данные помечаются как неустойчивые; через ~3 мин —
  установившиеся векторы (FR-TT-004). Обеспечивается процесс-шумом и начальной ковариацией фильтра.
* Манёвр цели: рост невязки → временное увеличение процесс-шума (адаптация) — запаздывание векторов
  при манёвре цели воспроизводится естественно.

### 3.6.3. Расчёт элементов сближения

Обозначения: `p = p_t − p_o` — относительное положение, `v = v_t − v_o` — относительная скорость.

```
ВКС (TCPA) = −(p · v) / |v|²                (если |v| ≈ 0 → не определено, цель «стоит» относительно нас)
ДКС (CPA)  = | p + v · ВКС |
```

Если ВКС < 0 — точка кратчайшего сближения пройдена, цель расходится.

**ДПК/ВПК** (BCR/BCT — дистанция и время пересечения курса). В системе, связанной с собственным судном
(ось `y'` — по курсу, `x'` — на правый борт), относительное движение `p'(t) = p'_0 + v'·t`:

```
ВПК = −p'_x0 / v'_x        (пересечение линии курса; ВПК > 0 — в будущем)
ДПК = p'_y(ВПК)            (> 0 — пересечёт по носу, < 0 — по корме)
```

Истинные курс и скорость цели: `К = atan2(v_tx, v_ty)`, `V = |v_t|`.

### 3.6.4. Тревоги САРП

| Тревога | Условие |
|---------|---------|
| Опасная цель (CPA/TCPA) | `ДКС < ДКС_пред` и `0 ≤ ВКС < ВКС_пред` (настраиваются оператором: на макете 2.00 мили / 30 мин) |
| Цель потеряна | K обзоров подряд без отметки у сопровождаемой цели |
| Вход в зону охраны | Новая отметка внутри зоны, не принадлежащая треку |
| Переполнение | Превышено число сопровождаемых целей |

### 3.6.5. Проигрывание манёвра (этап 2)

Оператор задаёт пробный курс/скорость и задержку `T_d`. Для всех треков рассчитывается ДКС/ВКС в
предположении, что собственное судно до `T_d` идёт прежним курсом, а затем мгновенно (MVP) или с
учётом циркуляции (этап 3) ложится на новый. Отображается символ «Т», векторы пересчитываются.

## 3.7. Движение

### Собственное судно

Модель первого порядка (достаточна для РЛС-тренажёра):

```
dV/dt = (V_зад − V) / T_v              T_v — постоянная разгона/торможения (60–300 с)
dK/dt = clamp(k_r·(K_зад − K), ±ω_max)  ω_max — макс. угловая скорость (по циркуляции)
скорость над грунтом = скорость по воде + течение
```

Параметры — в описании судна в сценарии. Номото-модель (руль → угловая скорость) — этап 3.

### Цели

| Модель | Параметры |
|--------|-----------|
| `constant` | курс, скорость |
| `route` | точки маршрута, скорость на участках, радиус поворота |
| `scripted` | список манёвров `{at: t, course, speed, rate}` |
| `static` | неподвижна (буй, якорная стоянка) |

## 3.8. Датчики собственного судна (этап 2)

* Гирокомпас: курс + постоянная ошибка + шум; отказ → ориентация переходит в «Нос», тревога.
* Лаг: скорость по воде + ошибка.
* ГНСС: координаты, курс/скорость над грунтом, шум ~3–10 м; отказ → нет широты/долготы курсора.

Важно: САРП и индикация используют **показания датчиков**, а не истинное состояние мира. Это позволяет
обучать распознаванию ошибок стабилизации.

## 3.9. Что сознательно упрощено

| Упрощение | Почему допустимо | Когда пересмотреть |
|-----------|------------------|--------------------|
| Плоская проекция | Район ≤ 100 миль | Сценарии океанских переходов |
