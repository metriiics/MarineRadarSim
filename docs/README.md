# MarineRadarSim — проектная документация

Учебный тренажёр судовой навигационной РЛС с функцией САРП (ARPA / Target Tracking).
Desktop-приложение на C++23 + Qt 6, работает автономно на одном ПК.

## Правила ведения документации

* Документация живёт в репозитории рядом с кодом и меняется в тех же PR, что и код.
* Каждое требование имеет стабильный ID (`FR-RAD-003`, `NFR-PERF-001`). ID не переиспользуются.
* Любое значимое архитектурное решение оформляется ADR в `docs/adr/` (шаблон — [adr/0000-template.md](adr/0000-template.md)).
* Открытые вопросы фиксируются в [10-risks-and-open-questions.md](10-risks-and-open-questions.md) с ID `Q-xxx`
  и закрываются ссылкой на принятое решение.
* Диаграммы — текстом (ASCII / Mermaid), чтобы они версионировались вместе с кодом.
