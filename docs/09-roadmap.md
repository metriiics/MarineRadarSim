# 09. План работ (Roadmap)

Итерации по 2 недели. Оценки — для одного разработчика полный день; это ориентир, а не обязательство.
Каждый этап заканчивается **работающей программой**, которую можно показать преподавателю.

## Этап 0. Фундамент (1 итерация)

| Задача | Результат |
|--------|-----------|
| Исправить сборку `main_window.cpp` (`smallBlocksColumn`) | Проект собирается |
| `.gitignore` (`build/`, `.cache/`), `.clang-format`, `.clang-tidy` | Чистый `git status` |
| CMake: разбиение на цели `mrs_core … mrs_presentation`, `CMakePresets.json`, FetchContent | Структура 04, §4.10 |
| GoogleTest + первый тест, `mrs_headless` (пустой) | `ctest` зелёный |
| spdlog, каталоги `logs/`, `results/` | Лог при запуске |
| `core`: единицы, `Bearing`, `LocalProjection`, `Rng` + тесты | Базовые типы |

**Готово, когда:** `cmake --preset debug && ctest` проходит, приложение показывает текущий макет.

## Этап 4. Обучение (2 итерации) → **Выпуск MVP 1.0**

## Этап 5. Развитие (после MVP)

* Запись/воспроизведение сеанса и разбор (FR-SES-004).
* Проигрывание манёвра (FR-TT-010), зоны охраны и автозахват (FR-TT-002).
* Датчики с отказами (FR-WLD-007, FR-SYS-005), стабилизация по воде/грунту (FR-TT-011).
* АПЧ, ПНП, ложные эхо (FR-RAD-010…012).
* GPU-отрисовка (ADR-0004), режим день/ночь.
* Задания уровня advanced.

## Этап 6+. Кандидаты

AIS, наложение карты, S-диапазон, рабочее место инструктора, экспорт отчёта в PDF, модель Номото.

2. Этап 0: починить сборку, разложить CMake по целям, поднять тесты.
3. Вертикальный срез этапа 1: одна цель, вращающаяся развёртка, отметка на ИКО — сквозь все слои.
