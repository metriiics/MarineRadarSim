# ADR-0001. Модульный монолит с послойными зависимостями

* Статус: принято
* Дата: 2026-10-18

## Контекст
Одно рабочее место, без сети, небольшая команда. Нужны тестируемость ядра и независимость от UI.

## Решение
Одно приложение, разделённое на статические библиотеки `core → domain → training/infrastructure →
application → presentation`. Направление зависимостей контролирует CMake: `domain` и `training`
собираются без Qt (пресет `headless`).

## Альтернативы
* Микросервисы / клиент-сервер — избыточно, нет требований к сети.
* Один «плоский» исполняемый файл — быстро на старте, но модель срастается с UI, тесты невозможны.

## Последствия
+ Ядро тестируется и запускается без GUI (`mrs_headless`).
+ Переход к сетевому варианту — добавлением транспорта к командам/снимкам.
− Нужна дисциплина: DTO-снимки вместо прямого доступа UI к объектам ядра.
