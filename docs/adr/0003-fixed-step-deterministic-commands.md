# ADR-0003. Фиксированный шаг симуляции и командная модель ввода

* Статус: принято
* Дата: 2026-10-18

## Контекст
Нужны воспроизводимость (оценивание, разбор, тесты), пауза и ускорение времени.

## Решение
* Симуляция выполняется тактами фиксированной длины (20 мс), время — целое число тактов.
* Все внешние воздействия — сериализуемые значения `Command`, применяемые в начале такта.
* Вся случайность — из детерминированного ГСЧ с seed сценария, отдельный поток на подсистему.
* Запись сеанса = сценарий + seed + `[{tick, command}]`.

## Альтернативы
* Переменный шаг от частоты кадров — невоспроизводимо.
* Запись снимков состояния вместо команд — большой объём, нет возможности «переиграть» с изменениями.

## Последствия
+ Replay, тест детерминизма, headless-прогоны.
− Запрет на системное время, неупорядоченные контейнеры с влиянием на результат, `-ffast-math` в ядре.
