# ADR-0002. Qt 6 Widgets для интерфейса

* Статус: принято
* Дата: 2026-10-18

## Контекст
Интерфейс — «приборный» пульт из панелей и одного графического ИКО. Требуются Linux и Windows.

## Решение
Qt 6 Widgets (макет уже начат). ИКО — собственный виджет (`QWidget` + `QPainter`/`QImage`, затем
`QOpenGLWidget`).

## Альтернативы
* Qt Quick/QML — лучше для анимаций и сенсорных экранов, но второй язык и более сложная отладка;
  преимущества не нужны для пульта.
* Dear ImGui — быстро, но плохо подходит для точного воспроизведения внешнего вида прибора.

## Последствия
+ Знакомая технология, готовые layouts, локализация через `tr()`.
− Qt ограничен слоями application/presentation; ядро от Qt не зависит (ADR-0001).
