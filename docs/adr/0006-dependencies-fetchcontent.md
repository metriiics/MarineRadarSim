# ADR-0006. Зависимости через CMake FetchContent

* Статус: принято
* Дата: 2026-10-18

## Контекст
На машине разработки из зависимостей установлен только Qt 6.4. Нужна одинаковая сборка на Linux и Windows.

## Решение
Qt — системный (`find_package`). Eigen, yaml-cpp, nlohmann_json, spdlog, GoogleTest — FetchContent с
фиксированными тегами; офлайн-сборка — из предзаполненного кэша (`FETCHCONTENT_FULLY_DISCONNECTED`).

## Альтернативы
* vcpkg/Conan — мощнее, но ещё один инструмент; пересмотреть при росте числа зависимостей.
* Системные пакеты — разные версии на разных ОС, на Windows их нет.

## Последствия
+ Сборка «из коробки» одной командой.
− Первая конфигурация требует сети (или кэша) и занимает время.
