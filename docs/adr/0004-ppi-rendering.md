# ADR-0004. Отрисовка ИКО: полярный растр + LUT, CPU в MVP, GPU позже

* Статус: принято
* Дата: 2026-10-18

## Контекст
Видео формируется спицами (2048 × 1024). Нужно ≥ 30 FPS с послесвечением на офисном ПК.

## Решение
UI хранит полярный растр и время обновления спиц. Кадр — выборка через предвычисленную таблицу
«пиксель → (спица, ячейка)», пересчитываемую при изменении геометрии. MVP — CPU (`QImage`).
Этап 2 — `QOpenGLWidget` с фрагментным шейдером по той же схеме; выбор пути — в конфигурации.

## Альтернативы
* Рисовать спицы `QPainter`-ом как линии — дырки и муар между спицами, медленно.
* Сразу GPU — риск на машинах без OpenGL 3.3, сложнее отладка.

## Последствия
+ Ориентация/смещение центра — только пересчёт LUT.
+ CPU-путь остаётся резервным.
− LUT ~ 4–8 МБ памяти на 1000×1000.
