# ADR-0005. Файлы вместо БД: YAML для входных данных, JSON для результатов

* Статус: принято
* Дата: 2026-10-18

## Контекст
Автономная работа, сценарии пишут люди, результаты читаются другими программами/людьми.

## Решение
YAML (yaml-cpp) — сценарии, задания, модели РЛС, типы судов. JSON (nlohmann_json) — результаты.
JSON Lines — запись сеанса. GeoJSON — береговая линия. Каждый файл имеет `schema_version`.

## Альтернативы
SQLite — нужен при сотнях обучаемых и выборках; добавим, когда появится требование к журналу группы.

## Последствия
+ Файлы читаются и правятся вручную, хранятся в git.
− Нет запросов по результатам — при необходимости внешний скрипт/отчёт.
